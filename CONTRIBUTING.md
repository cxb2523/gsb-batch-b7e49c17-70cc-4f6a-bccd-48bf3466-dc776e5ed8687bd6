# Contributing

Thanks for helping. The skills and README in this repo are generated, so the most useful contributions are issues: a request, a bug report with the exact error, or a note that an input or a field changed.

## Request a skill

Open an issue with the **Request a skill** form: https://github.com/bolvein-firex/scraping-skills/issues/new/choose

Say which site, which fields and what you do with the data. A site that already has a public Apify Actor is the quickest to add. Questions and ideas are welcome in Discussions: https://github.com/bolvein-firex/scraping-skills/discussions

## Report a problem

Use the **Bug report** form and include:

- the skill folder name,
- your agent and Node.js version,
- the error text from `scripts/run.mjs`,
- the input you used (remove your Apify token first).

## Pull requests

Small fixes are welcome: a typo, a wrong field name, a clearer setup step. These files are rewritten on each update, so a merged fix is also applied to the generator to keep it. For a new skill, open a request first.

Never commit tokens, sheet IDs, email addresses or pinned data. Public data only: no logins, cookies or paywalled pages.
