运行方式一（推荐，自动比对最新代码）：在仓库目录启动本地静态服务器，例如 python -m http.server 8000，然后访问 http://localhost:8000/boot-self-test.html。此时页面会直接读取当前 index.html 里的启动脚本作为被测对象，改过 index.html 也会自动测到最新版本。

运行方式二（离线）：直接双击打开本文件。浏览器禁止 file:// 页面读取本地文件，因此会回退到页面内嵌的启动脚本副本。内嵌副本是否与当前 index.html 一致，需按方式一运行才能校验。
