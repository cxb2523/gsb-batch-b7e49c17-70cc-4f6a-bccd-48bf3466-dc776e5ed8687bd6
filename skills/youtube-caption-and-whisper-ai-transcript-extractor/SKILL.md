# YouTube Caption & Whisper AI Transcript Extractor

Get timestamped transcripts from YouTube videos in your preferred language, with optional AI transcription for videos that have no captions at all. Returns full text, timed segments, and core video metadata.

- Actor: https://apify.com/nimbryxo-studio/youtube-caption-and-whisper-ai-transcript (ID `nimbryxo-studio~youtube-caption-and-whisper-ai-transcript`)
- n8n workflow for the same Actor: https://github.com/bolvein-firex/scraping-n8n-workflows/blob/main/docs/youtube-caption-and-whisper-ai-transcript-extractor.md
- Example input: `references/example-input.json`
- Input schema: `references/input-schema.json`
- Output fields: `references/output-fields.json`

## When to use

Use this skill when the user wants:

- YouTube caption scraper
- a repeatable export of public YouTube data as CSV or JSON

Do not use it for private, login-protected or paywalled data.

## What it returns

One JSON row per result. Columns from the Actor's dataset schema:

- `video_id`: Video id
- `title`: Title
- `channel_name`: Channel name
- `publishedAt`: Published At
- `transcript_language`: Transcript language
- `segment_count`: Segment count
- `success`: Success
- `transcript_available`: Transcript available
- `transcript_source`: Transcript source
- `accessStatus`: Access Status
- `errorCode`: Error Code
- `duration_seconds`: Duration seconds

All 31 declared fields: `references/output-fields.json`.

## Inputs

| Field | Type | Required | Default | Notes |
|---|---|---|---|---|
| `mode` | string | no | videos | What to scrape: specific videos, a channel's uploads, or a playlist. |
| `videoUrls` | array | no |  | YouTube watch URLs, youtu.be short links, Shorts/embed URLs, or plain 11-character video IDs (mode=videos). Duplicate IDs are processed once. |
| `channelUrls` | array | no |  | Channel URLs or handles (mode=channel), e.g. `https://www.youtube.com/@TED,` `https://www.youtube.com/channel/UC...,` or @TED. |
| `maxVideosPerChannel` | integer | no | 50 | Maximum number of videos to enumerate from each channel (mode=channel). 1-1,000. |
| `playlistUrls` | array | no |  | Playlist URLs or IDs (mode=playlist), e.g. `https://www.youtube.com/playlist?list=PL...` or PL.... Every video in the playlist is transcribed. |
| `maxVideosPerPlaylist` | integer | no | 50 | Maximum number of videos to enumerate from each playlist (mode=playlist). 1-1,000. |
| `language` | string | no |  | Caption language to fetch. Leave Auto-detect to use the video's original language. |
| `includeAutoGenerated` | boolean | no | true | Whether to include auto-generated captions when manual captions are not available. |
| `useWhisper` | boolean | no | true | When YouTube has no transcript (disabled captions, music-only, or blocked), download the audio and transcribe with Whisper AI (faster-whisper, CPU). Adds ~30-180 s per video. |
| `whisperModel` | string | no | base | Whisper model size to use when `useWhisper` is enabled. Larger = more accurate but slower and more RAM. 'base' is balanced. |
| `includeWordTimings` | boolean | no | false | Add a wordTimings array with word-level start/end times. Only auto-generated YouTube captions expose word timings; manual captions and AI transcripts do not. |
| `maxWhisperMinutes` | integer | no |  | Leave unset for the legacy behavior (AI enabled with no length limit). Set to 0 explicitly to disable AI transcription. |
| `proxyCountry` | string | no | US | Country/region for the proxy IP. Useful if transcripts are geo-blocked in the default US region. |
| `outputFormat` | string | no | full | How transcript data is included. 'full' = segments and full_text; 'text_only' = full_text only; 'segments_only' = segments only; 'srt' / 'vtt' = ready-to-use subtitle text derived… |

Example (`references/example-input.json`):

```json
{
  "videoUrls": [
    "https://www.youtube.com/watch?v=jNQXAC9IVRw"
  ],
  "whisperModel": "tiny",
  "proxyCountry": "GB"
}
```

The input passes the Actor's input schema (checked at every publish). First run: `maxVideosPerChannel` = 50, small enough for the 300-second sync wait; raise it once the rows look right.

## Run it

Set `APIFY_TOKEN`, then call the synchronous endpoint for small and medium runs (it waits up to 300 seconds):

```bash
curl -s -X POST "https://api.apify.com/v2/acts/nimbryxo-studio~youtube-caption-and-whisper-ai-transcript/run-sync-get-dataset-items" \
  -H "Authorization: Bearer $APIFY_TOKEN" \
  -H "Content-Type: application/json" \
  -d @references/example-input.json > output.json
```

Or with Node 18+: `node scripts/run.mjs [input.json]`.

For large runs, start an async run and read its dataset when it finishes:

```bash
RUN=$(curl -s -X POST "https://api.apify.com/v2/acts/nimbryxo-studio~youtube-caption-and-whisper-ai-transcript/runs" \
  -H "Authorization: Bearer $APIFY_TOKEN" -H "Content-Type: application/json" \
  -d @references/example-input.json)
RUN_ID=$(echo "$RUN" | jq -r '.data.id'); DATASET=$(echo "$RUN" | jq -r '.data.defaultDatasetId')
curl -s "https://api.apify.com/v2/actor-runs/$RUN_ID?waitForFinish=60" -H "Authorization: Bearer $APIFY_TOKEN" | jq -r '.data.status'
curl -s "https://api.apify.com/v2/datasets/$DATASET/items?format=json" -H "Authorization: Bearer $APIFY_TOKEN" > output.json
```
