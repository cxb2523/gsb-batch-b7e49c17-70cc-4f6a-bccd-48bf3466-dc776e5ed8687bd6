# 启动流程演示样例

本目录是 `index.html` 加固后启动流程的可本地运行演示。所有页面均为自包含静态文件，
**直接用浏览器打开即可**（支持 `file://` 协议，无需启动服务器）。

## 入口

用浏览器打开 `demo/index.html`，点击链接进入各演示页。每页底部会显示
绿色「验证通过」或红色「验证失败」横幅；启动失败时页面上方会出现红色错误区域，
写明失败阶段。

## 演示页面

| 页面 | 构造的输入 | 预期可见结果 |
| --- | --- | --- |
| `ok.html` | 正常密文（3 片模板） | 标题变为「演示标题：还原成功」，正文还原，内联脚本执行 |
| `missing-template.html` | 3 片模板只放 2 片 | 错误区域提示「模板缺失」，说明文字保留，页面不白屏 |
| `bad-base64.html` | 密文混入非法字符 | 错误区域提示「Base64 非法」，页面不白屏 |
| `empty-key.html` | 密钥为空字符串 | 错误区域提示「配置错误」，不进入解码循环 |
| `cross-origin-script.html` | 密文含跨域脚本、`javascript:` 脚本、白名单脚本 | 不可信脚本被拦截并记入错误区域、未插入 DOM；白名单脚本放行；内联脚本执行 |

演示页中的启动脚本由 `build_demos.py` 直接从仓库根目录 `index.html`
抽取并替换配置生成，保证演示与正式页逻辑一致。

## 重新生成与自检

```bash
python demo/build_demos.py   # 重新生成演示页面
node demo/selfcheck.js       # 密文往返、坏输入分支、脚本语法自检
```
